O que nunca fazer com a logo.
Oito erros recorrentes. Cada quadro mostra o erro de propósito, com a faixa vermelha de proibido.

- Não distorça, não gire, não recolora partes, não aplique sombra ou contorno.
- Não use a logo branca sobre fundo claro nem sobre foto sem película de `sobreposicao`.
- Não troque a fonte da palavra nem reescreva em maiúsculas.
- Não separe o ® nem mude a ordem símbolo e palavra.
- Não engrosse nem afine o traço à mão: a espessura vem da fórmula, por tamanho.
- Não use o contorno abaixo de 24 px: ali entra a versão sólida.

## Aplicações

| Código | Aplicação |
|---|---|
| `ERR-01` | Distorcer |
| `ERR-02` | Girar |
| `ERR-03` | Recolorir partes |
| `ERR-04` | Sombra ou contorno |
| `ERR-05` | Branca em fundo claro |
| `ERR-06` | Trocar a fonte |
| `ERR-07` | Separar o ® |
| `ERR-08` | Inverter a ordem |
| `ERR-09` | Engrossar o traço à mão |
| `ERR-10` | Contorno abaixo de 24 px |
