O selo que diz se a mistura é segura.
O componente mais importante do produto. Sempre **ícone e palavra**, nunca só cor: compatível, atenção, incompatível, sem dados e em análise.

- `ms-status--compativel`: `sucesso` sobre `sucesso-fundo`.
- `ms-status--atencao`: `atencao` sobre `atencao-fundo`. Mistura possível com cuidado (ordem, agitação, volume).
- `ms-status--incompativel`: `erro` sobre `erro-fundo`. Não misturar.
- `ms-status--sem-dados`: neutro. Nunca trate ausência de dado como compatível.
- `ms-status--analise`: `info`, enquanto o cálculo roda.
- Versão sólida para cabeçalho de receita e peças impressas.
