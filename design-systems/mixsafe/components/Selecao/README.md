Listas de escolha: fechada, aberta e múltipla.
Para escolher uma opção entre muitas (cultura, alvo, equipamento). Até cinco opções, prefira Radio.

- O item selecionado ganha marca de verificação e `sucesso`.
- A seleção múltipla mostra as escolhas como etiquetas acima da lista.

## Aplicações

| Código | Aplicação |
|---|---|
| `SEL-01` | Fechada |
| `SEL-02` | Aberta |
| `SEL-03` | Múltipla |
