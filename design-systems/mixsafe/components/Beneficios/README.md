Blocos de benefícios em colunas, grade e lista alternada.
Benefícios sem números inventados: cada bloco diz o que a pessoa ganha, com ícone do conjunto e texto de até três linhas.

## Aplicações

| Código | Aplicação |
|---|---|
| `BEN-01` | Três colunas |
| `BEN-02` | Quatro com fundo de superfície |
| `BEN-03` | Lista alternada |
