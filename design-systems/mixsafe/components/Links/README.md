Links em texto corrido, navegação e destinos externos.
- Links em texto: `destaque`, sempre sublinhados.
- Navegação: `ms-link--nav`, sem sublinhado; a página atual ganha `aria-current="page"` e o traço verde.
- Link externo: ícone de seta à direita e `rel="noopener"`.

## Aplicações

| Código | Aplicação |
|---|---|
| `LNK-01` | Em texto corrido |
| `LNK-02` | Navegação |
| `LNK-03` | Externo |
