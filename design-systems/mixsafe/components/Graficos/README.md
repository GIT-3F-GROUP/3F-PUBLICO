Barras, linha, rosca e medidor com as cores de série.
Séries: `serie-1` (azul), `serie-2` (verde), `serie-3` (azul claro no escuro, azul médio no claro). Grade em `borda`, textos em `texto-apagado`. Uma ideia por gráfico, legenda sempre visível.

## Aplicações

| Código | Aplicação |
|---|---|
| `GRF-01` | Barras |
| `GRF-02` | Linha com área |
| `GRF-03` | Rosca |
| `GRF-04` | Medidor |
