Números-chave do painel.
Use indicadores só quando o número é o assunto da tela (painel da safra). Cada um: rótulo com ícone, valor em Exo 36 px com unidade, variação com contexto. Valores deste exemplo são ilustrativos.

## Aplicações

| Código | Aplicação |
|---|---|
| `KPI-01` | Área aplicada |
| `KPI-02` | Caldas validadas |
| `KPI-03` | Alertas resolvidos |
| `KPI-04` | Destaque de marca |
