Posts, stories e capas para redes sociais.
Peças de rede: logo sempre presente (canto inferior ou topo), frase em Exo ExtraBold Italic minúscula, fundo de marca. Uma mensagem por peça.

- Quadrado 1080 x 1080, retrato 1080 x 1350, story 1080 x 1920, capa LinkedIn 1584 x 396.
- Margem interna de 8 % do lado menor.
