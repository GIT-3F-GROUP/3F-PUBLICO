Caixas de seleção para itens independentes.
Para marcar itens independentes (produtos de uma lista, termos). O quadrado usa `raio-1`, marcado em `acao`.

## Aplicações

| Código | Aplicação |
|---|---|
| `CHK-01` | Desmarcada |
| `CHK-02` | Marcada |
| `CHK-03` | Parcial |
| `CHK-04` | Desabilitada |
