A matriz que cruza cada par de produtos.
Cada célula cruza dois produtos. Ícone dentro da célula e legenda sempre visível. A diagonal fica vazia.

- 3 a 8 produtos na tela; acima disso, use a lista de pares com problema.
- Valores ilustrativos: nunca publique uma matriz como recomendação técnica sem validação agronômica.

## Aplicações

| Código | Aplicação |
|---|---|
| `MTZ-01` | Três produtos |
| `MTZ-02` | Cinco produtos |
| `MTZ-03` | Com legenda |
