Etiquetas de filtro e de categoria.
Etiquetas em cápsula. Filtros alternam com `aria-pressed`; etiquetas sólidas só informam (formulação, cultura).

## Aplicações

| Código | Aplicação |
|---|---|
| `ETQ-01` | Filtros |
| `ETQ-02` | Filtro com ícone |
| `ETQ-03` | Formulação |
| `ETQ-04` | Removível |
