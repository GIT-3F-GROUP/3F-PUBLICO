Campos de texto com rótulo, ajuda, unidade e estados.
**O que o consumidor fornece:** rótulo sempre visível (nunca só placeholder), texto de ajuda quando houver regra, unidade de medida no sufixo.

- Altura 44 px, `raio-2`, borda `borda-forte`, fundo `superficie`.
- Foco: borda `foco` e anel `foco-anel`.
- Erro: borda e mensagem em `erro`, com o que fazer para corrigir.
- Números de campo levam a unidade dentro do campo (L/ha, mL, °C, %).

## Aplicações

| Código | Aplicação |
|---|---|
| `CAM-01` | Padrão |
| `CAM-02` | Com foco |
| `CAM-03` | Preenchido |
| `CAM-04` | Erro |
| `CAM-05` | Sucesso |
| `CAM-06` | Desabilitado |
| `CAM-07` | Com unidade |
| `CAM-08` | Com ícone à esquerda |
| `CAM-09` | Área de texto |
