Envio de bula, laudo de água e receituário.
Área de soltar arquivos com alternativa de clique. Liste formatos e tamanho máximo. Depois do envio, mostre o arquivo com nome, tamanho e ação de remover.

## Aplicações

| Código | Aplicação |
|---|---|
| `UPL-01` | Pronta |
| `UPL-02` | Arrastando |
| `UPL-03` | Arquivo enviado |
