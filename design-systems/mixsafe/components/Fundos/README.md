Fundos de marca: sólidos e os degradês oficiais.
O fundo preferencial é `azul-business-04`. Os degradês vão sempre do mais escuro para `azul-business-03` ou, no máximo, `azul-business-02`, e nunca passam para tons claros.

- `--ms-degrade-marca`: 160°, `azul-business-03` a `azul-business-04`. Padrão para hero e capa.
- `--ms-degrade-radial`: luz central, para destacar a logo.
- `--ms-degrade-profundo`: diagonal com `azul-business-02` no canto, para peças de campanha.
- `--ms-degrade-luz`: ponto de luz no canto superior esquerdo, para login e faixas de chamada.
- `--ms-degrade-horizonte`: vertical, para cabeçalhos internos.
- `--ms-degrade-noite`: `azul-business-04` a `azul-noite`, para rodapé e modo foco.
- Texto sobre qualquer degradê: `branco` ou `texto-suave` do tema escuro.
