Cabeçalhos do site: fixo, sobre hero e celular.
O cabeçalho carrega o logotipo à esquerda com 30 px de altura (24 px no celular), navegação à direita e uma ação principal.

- Sobre hero de marca use a versão transparente; ao rolar, troque para `fundo` com borda `borda`.
- No celular o menu abre em gaveta de tela cheia com itens em Exo 18 px.

## Aplicações

| Código | Aplicação |
|---|---|
| `CAB-01` | Desktop |
| `CAB-02` | Transparente sobre hero |
| `CAB-03` | Celular fechado |
| `CAB-04` | Celular com menu aberto |
