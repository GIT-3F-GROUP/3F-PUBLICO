Conversa com o assistente de calda.
O assistente responde em frases curtas, cita a fonte (bula, laudo) e termina com uma ação possível. A mensagem dele é assinada pelo símbolo.

## Aplicações

| Código | Aplicação |
|---|---|
| `IA-01` | Pergunta |
| `IA-02` | Resposta |
| `IA-03` | Sugestões rápidas |
| `IA-04` | Digitando e caixa de mensagem |
