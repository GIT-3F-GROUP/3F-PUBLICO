A sequência em que os produtos entram no tanque.
Lista numerada, porque aqui a ordem é informação. Cada linha: número, produto, formulação e dose.

- Sequência de referência por formulação (água, condicionador, WG, SC, EC, SL, adjuvante). Confirme sempre com a bula.

## Aplicações

| Código | Aplicação |
|---|---|
| `ORD-01` | Lista completa |
| `ORD-02` | Em linha |
| `ORD-03` | Em execução no campo |
