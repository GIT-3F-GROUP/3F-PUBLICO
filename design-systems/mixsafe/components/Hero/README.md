Aberturas de página: centrada, dividida e compacta.
O hero abre a página com uma frase em `display` Exo ExtraBold Italic, uma linha de apoio e no máximo duas ações. Fundo sempre de marca.

## Aplicações

| Código | Aplicação |
|---|---|
| `HER-01` | Centrado com logo |
| `HER-02` | Dividido com tela do produto |
| `HER-03` | Compacto para páginas internas |
