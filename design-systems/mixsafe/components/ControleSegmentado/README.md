Alternância entre duas a quatro visões mutuamente exclusivas.
Grupo de cápsulas para trocar a visão de um mesmo conteúdo (lista, grade, mapa). Use `aria-pressed` no botão ativo.

- De duas a quatro opções, rótulos de uma ou duas palavras.
- Para navegar entre conteúdos diferentes, use Abas.

## Aplicações

| Código | Aplicação |
|---|---|
| `SEG-01` | Texto |
| `SEG-02` | Ícone e texto |
| `SEG-03` | Unidade de medida |
