Ícone de linha do sistema — Lucide, traço 1,5 px, cantos retos, sempre em Verde Sombra (ou branco no escuro) com variação por opacidade, nunca por cor.

```jsx
<Icon name="map-pin" /> <Icon name="trending-up" size={24} /> <Icon name="layers" />
```

Carregue `https://unpkg.com/lucide@latest` na página. Ícones nunca recebem cor da paleta neon.
