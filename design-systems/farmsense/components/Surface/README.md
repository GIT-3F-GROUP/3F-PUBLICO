Fundo de seção completo, com padrão ambiente já embutido. É a peça que dá ritmo a uma página.

```jsx
<Surface variant="grade"><h1 className="display">Agronomia de precisão</h1></Surface>
<Surface variant="rastro">…</Surface>
```

Máximo de duas superfícies escuras por página. Alterne clara → escura → clara; nunca duas iguais em sequência.
