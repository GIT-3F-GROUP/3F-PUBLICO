# Cores principais e secundárias

Principais: branco (#FFFFFF) e preto ORVIX (#101720, nunca o preto absoluto). Secundárias: claro ORVIX (#E8EAEE) e verde (#13A538). Cinzas web, base do tema claro: Web 1 (#F0F2F4) é o fundo de página, o hover e a linha alternada; Web 2 (#DCE1E4) é borda, divisor e hairline; Web 3 (#C8CFD4) entra pouco, em contorno de campo e borda forte. Tokens `branco`, `preto`, `claro`, `verde`, `web-1`, `web-2`, `web-3`.
