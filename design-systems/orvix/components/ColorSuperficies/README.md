# Superfícies e temas

Dois temas (`dark` padrão, `light`) com as mesmas camadas: `bg-deep`, `bg`, `surface-1` a `surface-4`. Cada camada é um passo de tom acima da anterior (tom sobre tom). Nunca uma caixa clara sobre fundo escuro, nem o inverso. Ative o claro com `data-theme="light"` no `html` ou em qualquer bloco.
