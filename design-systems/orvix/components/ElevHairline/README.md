# Hairline antes de sombra

A separação entre blocos vem da linha de 1px com uma sombra baixa e suave: `--shadow-1` ou, no máximo, `--shadow-2`. Nunca sombra longa e escura de elevação.

Página de especificação migrada de `guidelines/elev-hairline.html`, HTML puro com as classes do sistema: copie o markup. Desenha-se sobre o palco escuro `.ovx-stage` e usa grade fluida (`auto-fit`), sem largura fixa.
