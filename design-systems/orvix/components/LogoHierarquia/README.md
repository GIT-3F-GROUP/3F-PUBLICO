# Hierarquia das logos

As oito marcas oficiais, uma a uma, em bloco próprio: papel, quando usar, o que nunca fazer, pernas e opacidades, tamanho mínimo, proporção e arquivo. Principal, quadrada, X com detalhe mínimo, sem detalhes, para vídeos, Elemento X, Elemento ORVIX e Clube ORVIX. Nenhuma outra logo entra no sistema.
