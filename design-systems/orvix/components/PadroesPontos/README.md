# Padrões de pontos

A malha de pontos da marca como padrão de fundo: densa (4px), sempre suave (claro a 6%, no máximo 10%), em versão cheia ou em degradê de transparência (vertical, horizontal, radial, diagonal, faixa). O degradê nunca muda de cor. Classes `orvix-dots--suave` mais `orvix-dots--fade-*`; componente `XTexture tone="suave" fade="…"`. Fundo por trás sempre preto ou degradê de preto para grafite, nunca com verde.
