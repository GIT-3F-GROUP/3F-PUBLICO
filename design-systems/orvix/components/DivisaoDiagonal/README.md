# Divisão diagonal

A ORVIX nunca divide uma tela em linha reta. A divisória segue o ângulo da perna do X da logo principal, 30,5° a partir da vertical (`--x-leg-angle`; `--split-angle` 120,5° para gradiente e máscara), topo à direita e base à esquerda. Componente `SplitDiagonal` e classes `.ovx-split`; a proporção muda com `--split-at`, o ângulo nunca. Abaixo de 640px as metades empilham.
