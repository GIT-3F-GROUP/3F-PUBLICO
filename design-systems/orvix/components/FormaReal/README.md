# Fidelidade de forma

Regra de criação para infográficos, elementos gráficos, ícones e movimento: tudo o que representa algo real segue as formas, as proporções e as inclinações do mundo real, sem buscar realismo. Gota é gota (nunca círculo), gota sobre a folha é calota com ângulo de contato real (alto sem adjuvante, lente baixa com a tensão quebrada), folha tem nervuras e ponta assimétrica (nunca elipse) e o leque de bico abre no ângulo do modelo. Partícula abstrata pode ser ponto; gota, folha, bico e planta, não.
