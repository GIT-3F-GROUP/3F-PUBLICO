# Logos ORVIX

As oito marcas oficiais, cada uma em preto puro (`-preto.svg`) e branco puro (`-branco.svg`): principal, quadrada, X com detalhe mínimo, sem detalhes, para vídeos, Elemento X, Elemento ORVIX e Clube ORVIX; mais as quatro logos com nome sem a assinatura AGROQUÍMICA (`-sem-assinatura-preto.svg` e `-branco.svg`). Cada arquivo tem a camada `ARTE` com os grupos `X` (perna sólida e `P1`, `P2`, `P3` com opacidade declarada), o nome e a assinatura. Tinta única: preto ou branco; o tema escolhe. Nenhuma outra logo entra no sistema. Veja a seção Logos do README e os cards Logo.
