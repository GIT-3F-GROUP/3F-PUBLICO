Abertura de página interna: trilha, título de 48px e apoio.

## Quando usar

- Toda página que não é a home: blog, vagas, contato, páginas legais e telas internas.

## Variações desenhadas

- Com trilha
- Com ações
- Com abas

## Regras

- Trilha, título de 48px (32px no celular) e uma frase de apoio.
- Ações da página à direita do título; abas logo abaixo.
- Recuo vertical de 48px; a borda inferior separa do conteúdo.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
