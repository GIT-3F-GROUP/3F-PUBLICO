Etapas de um processo em sequência.

## Quando usar

- Formulários longos, candidatura e cadastro em etapas.

## Variações desenhadas

- Três etapas
- Quatro etapas, concluído

## Regras

- De três a cinco etapas. Feita: fio em `texto`. Atual: fio em `acento-solido`. Futura: fio em `borda`.
- Cada etapa tem número e nome curto.
- O usuário volta para etapas feitas; não pula para as futuras.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
