Linha de separação, simples ou com rótulo.

## Quando usar

- Entre blocos de um mesmo cartão ou formulário.
- Com rótulo: separa alternativas, como "ou".

## Variações desenhadas

- Simples
- Com rótulo
- Entre blocos

## Regras

- 1px em `borda`. Entre seções, o divisor é a borda superior da própria seção.
- Prefira espaço a linha: use o divisor só quando o espaço não basta.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
