Lista de linhas com ícone, texto e valor ou seta.

## Quando usar

- Menus de configuração, resultados de busca, documentos e contatos.

## Variações desenhadas

- Com seta
- Com valor
- Documentos

## Regras

- Linha de pelo menos 56px, com 1px de separação.
- Título em peso 500 e uma linha de apoio em 12px.
- Linha clicável termina em `chevron-right`; linha informativa termina no valor.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
