Etiqueta de estado: neutra, positiva, de aviso, de alerta, de contorno e forte.

## Quando usar

- Estado de um registro em tabela, cartão ou cabeçalho de página.

## Variações desenhadas

- Neutro
- Positivo
- Aviso
- Alerta
- Contorno
- Forte
- Variação positiva
- Variação negativa
- Sem variação

## Regras

- Raio `radius-md` (6px), 12px em peso 500.
- A palavra diz o estado; a cor só reforça. Estado crítico leva também ponto ou ícone.
- Uma a duas palavras: "Ativa", "Em análise", "Em construção".
- Selo não é botão: não recebe clique.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
