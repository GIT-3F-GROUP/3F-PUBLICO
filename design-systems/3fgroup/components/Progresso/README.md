Andamento de uma tarefa: barra e indicador giratório.

## Quando usar

- Barra: quando se sabe quanto falta.
- Giratório: espera curta e sem medida.

## Variações desenhadas

- Barra com rótulo
- Barra neutra
- Concluída
- Giratório

## Regras

- Barra de 6px em `acento-solido` sobre `superficie-3`; a versão neutra usa `texto`.
- A barra leva rótulo e percentual em texto.
- O giratório é o ícone `loader` e é um dos poucos laços permitidos.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
