Etiqueta de cantos levemente arredondados para categoria, segmento e filtro.

## Quando usar

- Categoria de artigo e segmento de empresa.
- Opção de filtro; no estado aplicado, fica verde.
- Marcador removível de uma seleção.

## Variações desenhadas

- Padrão
- Hover
- Com ícone
- Com contagem
- Filtro aplicado
- Filtro removível
- Grupo de categorias
- Barra de filtros

## Regras

- Raio `radius-md` (6px), nunca pílula. 12px em peso 500.
- Padrão: borda `borda`, fundo `superficie`, texto `texto-2`. Hover escurece borda e texto.
- Filtro aplicado: `acento-fundo`, `acento-borda`, texto `acento` em peso 700.
- Rótulo de uma a três palavras. Chip clicável é `<button>` ou `<a>`.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
