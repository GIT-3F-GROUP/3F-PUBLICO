Lista ordenada com barra de proporção.

## Quando usar

- Maiores clientes, produtos e regiões em um painel.

## Variações desenhadas

- Cinco primeiros

## Regras

- Posição, nome e valor na mesma linha; barra de 6px abaixo.
- De cinco a dez linhas.
- A barra é proporcional ao primeiro colocado.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
