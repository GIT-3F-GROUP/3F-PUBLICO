Campo de várias linhas para mensagem e observação.

## Quando usar

- Mensagem de contato, observação, descrição.

## Variações desenhadas

- Vazia
- Preenchida, com ajuda

## Regras

- Mesma borda, raio e foco de `Entrada`. Altura mínima de 112px; o usuário pode aumentar na vertical.
- Rótulo sempre visível. Limite de caracteres, quando houver, aparece na ajuda.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
