Lista de escolha única em campo fechado.

## Quando usar

- Escolha entre cinco ou mais opções conhecidas. Até quatro, prefira `Radio`.

## Variações desenhadas

- Fechada
- Sem escolha
- Com erro

## Regras

- É o `select` nativo com a classe `.entrada`, para funcionar bem em celular e com leitor de tela.
- A primeira opção é neutra ("Selecione") quando não há padrão seguro.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
