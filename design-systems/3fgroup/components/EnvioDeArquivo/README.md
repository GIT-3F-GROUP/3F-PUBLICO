Área de envio de arquivo e linha de arquivo anexado.

## Quando usar

- Currículo, documento e imagem enviados pelo usuário.

## Variações desenhadas

- Área de envio
- Arquivo anexado
- Enviando

## Regras

- Área tracejada em `borda-tracejada`, raio `radius-xl`, com ícone, instrução e formatos aceitos.
- Depois do envio, o arquivo vira uma linha com nome, peso e ação de remover.
- Diga o formato e o peso máximo antes do envio.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
