Dados de contato ao lado do formulário.

## Quando usar

- Página de contato e fim de páginas de serviço.

## Variações desenhadas

- Com formulário
- Só dados

## Regras

- Duas colunas: dados à esquerda, formulário à direita; uma coluna no celular.
- Dados em lista de definições; nada de mapa decorativo.
- Horários sempre no fuso de Sorriso e Cuiabá.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
