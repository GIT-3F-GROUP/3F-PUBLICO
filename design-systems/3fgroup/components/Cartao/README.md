Cartão de conteúdo: simples, com imagem, clicável, com rodapé, horizontal e elevado.

## Quando usar

- Agrupar um título, um texto curto e, no máximo, uma ação.
- Elevado: só na área interna e no BI.

## Variações desenhadas

- Simples
- Com ação
- Clicável, em hover
- Com imagem
- Com rodapé
- Elevado (área interna)
- Horizontal
- Com selo

## Regras

- Raio `radius-xl` (12px), borda `borda`, fundo `superficie`, recuo de 24px.
- Um título de 18px, um texto de até três linhas e uma ação.
- Clicável: o cartão inteiro é o link; no hover a borda vai a `borda-forte`.
- No portal o cartão não tem sombra. O elevado troca a borda por `sombra-cartao`.
- Cartões de uma mesma grade têm a mesma estrutura e a mesma altura.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
