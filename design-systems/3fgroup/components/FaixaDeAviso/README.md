Faixa estreita no topo da página com um aviso e um link.

## Quando usar

- Comunicado institucional, evento e manutenção programada.

## Variações desenhadas

- Com link
- Manutenção

## Regras

- Uma frase e um link. Sem ícone decorativo.
- Preta no claro e `superficie-2` no escuro.
- Uma faixa por vez, com data para sair do ar.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
