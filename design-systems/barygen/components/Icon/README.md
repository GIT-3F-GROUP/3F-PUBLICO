Ícone de linha oficial da BARYGEN: use sempre que uma interface precisar de um glifo; nunca desenhe SVG novo à mão.

```jsx
<Icon name="baixar" size={16} strokeWidth={2} />
```

Herda a cor do texto (`currentColor`): nunca multicolorido. Dentro de botões use `size={16}` e `strokeWidth={2}`; em listas e menus, `size={16}` com traço 1,5. O conjunto oficial tem 15 glifos; para necessidades além dele use Lucide (mesma família de traço) e registre a exceção.
