A única textura da marca: pontos adensados com opacidade de 0 a 15%, a ser usada com cautela.

Use `class="bry-tex-pontos"` em fundo claro e `class="bry-tex-pontos bry-tex-pontos--escuro"` em fundo escuro. A camada de pontos (1,4 px a cada 4 px) fica atrás do conteúdo, a 15% no máximo. Para a textura sumir até o totalmente transparente, some `--fade-baixo`, `--fade-cima`, `--fade-lado` ou `--fade-canto`. No máximo uma área texturizada por tela, nunca sob texto de leitura longa, tabela ou formulário; na dúvida, sem textura.
