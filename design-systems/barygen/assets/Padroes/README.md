# Padrões

`Padrão milho Van Gogh 230 px.png`: o padrão de milho Van Gogh, um módulo de 230 × 230 px que repete na horizontal e na vertical. Use sempre no tamanho original. É tratado como imagem: nunca recebe texto por cima. Para texto na mesma seção, use as Seções Van Gogh (Efeitos › Seções Van Gogh), com a forma amarela de cima a baixo.

Uso: alternativa rara, quando pedirem; é o fundo indicado (e pode ser sugerido) quando o assunto é só a própria BARYGEN, como empresa e origem.
