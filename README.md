# 3F-PUBLICO
## 3F Group Design System

A pasta [`design-system/project/`](design-system/project/) guarda o design system completo da 3F Group, no formato do tipo Design System do Claude:

- `README.md`: o brand book (fundamentos de conteúdo, visuais, marca e uso).
- `tokens.json`: cores (temas Claro e Escuro BI), tipografia, espaçamento, raios e sombras.
- `components/`: 95 componentes, cada um com `README.md` (diretrizes) e `preview.html` (prévia viva), mais `bundle.css` e a capa (`Cover`).
- `fonts/`: Be Vietnam Pro (Regular, Medium, Bold, ExtraBold e itálicos).
- `assets/Logos` e `assets/Empresas`: as 28 logos em SVG ficam no armazenamento de assets do artifact; `design-system.json` lista cada uma.
