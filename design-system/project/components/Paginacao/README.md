Troca de página em listas longas.

## Quando usar

- Blog, vagas e tabelas com mais de uma página.

## Variações desenhadas

- Numerada
- Anterior e próxima
- Carregar mais

## Regras

- Página atual em `acao` com texto `sobre-acao`; as demais em `texto-2`.
- Mostre no máximo sete posições; o resto vira reticências.
- No celular, só "Anterior" e "Próxima".
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
