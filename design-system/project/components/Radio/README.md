Escolha única entre poucas opções, em linha simples ou em cartão.

## Quando usar

- De duas a quatro opções que se excluem.
- Cartão de opção: quando cada escolha precisa de uma linha de explicação.

## Variações desenhadas

- Lista
- Em linha
- Cartões de opção

## Regras

- Controle nativo com `accent-color` em `verde-3f`.
- Cartão de opção escolhido: `acento-fundo` e `acento-borda`.
- Sempre uma opção já escolhida quando houver padrão seguro.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
