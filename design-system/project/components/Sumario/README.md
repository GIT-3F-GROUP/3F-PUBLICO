Índice das seções de uma página longa.

## Quando usar

- Artigos longos, páginas legais e documentação.

## Variações desenhadas

- Com seção atual

## Regras

- Fio vertical de 1px; a seção atual em peso 700 com fio em `texto`.
- Fica preso ao lado do texto a partir de 1024px; no celular, vira uma `Selecao`.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
