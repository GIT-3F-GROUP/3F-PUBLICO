Caixa de marcar para escolhas independentes e consentimento.

## Quando usar

- Uma ou várias opções que se somam.
- Consentimento (LGPD): sempre desmarcada de início.

## Variações desenhadas

- Desmarcada
- Marcada
- Desabilitada
- Consentimento
- Lista

## Regras

- Controle nativo com `accent-color` em `verde-3f`. O rótulo inteiro é clicável.
- Texto do rótulo em 14px. Consentimento nunca vem marcado.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
