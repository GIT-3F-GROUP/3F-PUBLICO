Sobretítulo em caixa alta que abre cada seção, acima do título.

## Quando usar

- Uma vez por seção, acima do título.
- Título de coluna no rodapé.

## Variações desenhadas

- Simples
- Com ponto mediano
- Acima do título

## Regras

- 12px, peso 700, espaçamento de letras de 0.22em, cor `texto-3`.
- De uma a quatro palavras. Mais de um termo se separa por ponto mediano.
- Fica a 12px do título.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
