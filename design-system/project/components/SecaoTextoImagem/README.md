Texto de um lado e imagem do outro.

## Quando usar

- Apresentar uma empresa, um serviço ou uma história com uma foto.

## Variações desenhadas

- Imagem à direita
- Imagem à esquerda

## Regras

- Duas colunas iguais, com 48px de vão; a imagem vai acima do texto no celular.
- Imagem em 4:3. Texto: sobretítulo, título, um parágrafo e um link.
- Em seções seguidas, alterne o lado da imagem.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
