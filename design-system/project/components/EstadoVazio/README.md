O que a tela mostra quando não há conteúdo, resultado ou página.

## Quando usar

- Lista vazia, busca sem resultado, página fora do ar e erro 404.

## Variações desenhadas

- Lista vazia
- Busca sem resultado
- Página não encontrada
- Sem permissão

## Regras

- Ícone de 22px, título de 18px, uma frase e uma ação.
- O texto diz o que fazer para sair do vazio.
- Moldura tracejada em listas; sem moldura em página inteira.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
