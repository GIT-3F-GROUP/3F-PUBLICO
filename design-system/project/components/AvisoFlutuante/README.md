Aviso curto que aparece e some sozinho.

## Quando usar

- Confirmar uma ação que não muda a página: copiar, salvar, arquivar.

## Variações desenhadas

- Simples
- Com desfazer

## Regras

- Uma frase de até seis palavras; no máximo uma ação, como "Desfazer".
- Fundo `acao`, texto `sobre-acao`, raio `radius-xl`, `sombra-flutuante`.
- Surge no canto inferior, fica cerca de cinco segundos e some.
- Erro que exige ação não é aviso flutuante: é `Alerta`.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
