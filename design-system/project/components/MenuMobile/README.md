Painel de navegação do celular.

## Quando usar

- Abaixo de 1024px, aberto pelo botão de menu do cabeçalho.

## Variações desenhadas

- Aberto

## Regras

- Fundo opaco `fundo`, fora do `<header>`, com altura medida em `dvh`.
- Linhas de 52px, com 16px em peso 500 e `chevron-right`.
- A ação principal fecha o painel, em largura total.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
