Ajuste de quantidade com menos e mais.

## Quando usar

- Quantidade pequena e inteira, como itens de um pedido.

## Variações desenhadas

- Padrão
- Com rótulo

## Regras

- Botões de 44px com `minus` e `plus`; valor central em peso 500.
- Cada botão leva `aria-label`.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
