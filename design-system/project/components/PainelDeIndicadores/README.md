Tela de indicadores montada: título, filtros, indicadores e gráficos.

## Quando usar

- Tela inicial do BI e de cada painel por empresa.

## Variações desenhadas

- Tela montada

## Regras

- Ordem fixa: título da tela, barra de filtros, linha de indicadores, gráficos, tabela.
- Quatro indicadores por linha no desktop, dois no celular; 16px entre cartões.
- Os valores de exemplo são ilustrativos.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
