Círculo com foto ou iniciais de uma pessoa.

## Quando usar

- Autor, usuário logado, responsável por um registro.

## Variações desenhadas

- Pequeno · 28px
- Médio · 40px
- Grande · 64px
- Com nome
- Grupo

## Regras

- É a única peça circular do sistema, ao lado do ponto indicador.
- Três tamanhos: 28, 40 e 64px.
- Sem foto: duas iniciais em peso 700 sobre `superficie-2`.
- Em grupo, os avatares se sobrepõem 8px, com no máximo cinco visíveis.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
