Forma cinza que ocupa o lugar do conteúdo enquanto ele carrega.

## Quando usar

- Telas que demoram mais de meio segundo para trazer dados.

## Variações desenhadas

- Cartão
- Linhas de lista
- Indicador

## Regras

- Blocos em `superficie-3`, com o formato do conteúdo que vem.
- Surge em 500ms e pulsa raso (0.9 a 0.55) a cada 2.6s.
- Some de uma vez quando o conteúdo chega.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
