Link de texto: no meio da frase, com seta, externo e discreto.

## Quando usar

- No meio do texto: sublinhado.
- Com seta: chamada no fim de um bloco ou de um cartão.
- Discreto: rodapé, metadado e navegação secundária.

## Variações desenhadas

- No meio do texto
- Com seta
- Externo
- Discreto
- Voltar
- Baixar arquivo

## Regras

- Link no texto é sempre sublinhado, com afastamento de 3px; a cor é a do texto.
- Link com seta usa `arrow-right` de 14px; no hover a seta se afasta 4px.
- Link externo leva o ícone `external` e abre em nova aba com `rel="noopener"`.
- O texto do link diz o destino: "Ler o blog", nunca "clique aqui".
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
