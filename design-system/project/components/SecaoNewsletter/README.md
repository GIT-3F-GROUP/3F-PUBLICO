Convite para assinar a newsletter, com o campo na própria seção.

## Quando usar

- Home, fim de artigo e página da newsletter.

## Variações desenhadas

- Duas colunas
- Confirmada

## Regras

- Título, uma frase e o formulário em uma linha.
- Abaixo do campo, a frase de consentimento com link para a política.
- Depois do envio, o formulário dá lugar a um `Alerta` de confirmação.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
