A paleta em uso, com o papel de cada cor nos dois temas.

## Quando usar

- Consultar antes de escolher qualquer cor.

## Variações desenhadas

- Marca
- Escala web
- Superfícies do tema
- Texto e ação do tema
- Estados

## Regras

- Preto, branco e a escala web carregam a marca; o verde entra no logo e nos estados.
- Em interface, use os tokens de tema (`fundo`, `superficie`, `texto`, `borda`, `acao`, `acento`), que trocam sozinhos entre claro e escuro.
- Verde, âmbar e vermelho só comunicam estado, sempre com palavra ou ícone junto.
- Nenhuma cor fora desta paleta entra em peça do grupo.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
