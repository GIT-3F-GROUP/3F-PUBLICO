Três ideias lado a lado: pilares, valores ou diferenciais.

## Quando usar

- Missão, visão e valores; pilares de um serviço; três razões.

## Variações desenhadas

- Três colunas
- Em grade de 1px
- Em fundo alternado

## Regras

- Sempre três colunas no desktop e uma no celular. Para quatro itens, use `SecaoRecursos`.
- Cada coluna: sobretítulo opcional, título de 24px e um parágrafo de até três linhas.
- As três colunas têm a mesma estrutura e tamanhos parecidos de texto.
- Vale nos dois temas: as cores vêm dos tokens de tema, nunca de valor fixo.
